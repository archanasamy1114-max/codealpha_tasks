# Netflix Movies and TV Shows - Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a Netflix Movies and TV Shows dataset.

The main objective is to understand the dataset, identify missing values, explore patterns, and find useful insights from Netflix content data.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset structure analysis
- Data type analysis
- Missing value analysis
- Duplicate value analysis
- Data cleaning
- Movies vs TV Shows analysis
- Rating analysis
- Release year analysis
- Country analysis
- Genre analysis
- Data visualization

## Key Findings

- The dataset contains Movies and TV Shows available on Netflix.
- Movies form a larger portion of the dataset than TV Shows.
- TV-MA is one of the most common content ratings.
- The United States and India are major contributors to the dataset.
- Netflix content shows significant growth in recent years.
- Missing values were identified and handled during data cleaning.

## Project Files

- `eda_analysis.ipynb` - Complete EDA analysis
- `cleaned_netflix_data.csv` - Cleaned dataset
- `dataset/netflix_titles.csv` - Original dataset

## Conclusion

This project helped identify important patterns in Netflix content using Python-based Exploratory Data Analysis and data visualization.
